# 🚀 Quick Start Guide: How to Launch the Conspiracy Theater

## 🎭 Two Ways to Start

### **Method 1: Easy Launch (Recommended)**
Simply double-click:
```
launch.bat
```
Choose **Option 2** to launch the Streamlit theater interface!

### **Method 2: Command Line**
```bash
# Activate virtual environment
spectral_env\Scripts\activate

# Launch Streamlit theater
python -m streamlit run core/theater/civic_theater_stage.py
```

**✅ CONFIRMED WORKING:** Streamlit opens at **http://localhost:8501**

## 🕵️ How to Use Conspiracy Theater Mode

### Step 1: Open Browser
- Theater opens at: **http://localhost:8501**
- You'll see the main interface

### Step 2: Select Satellite Image
- Browse images in the interface
- Click on any Prague satellite image
- **Don't worry about what's hidden inside!**

### Step 3: Choose Conspiracy Theater Mode
- Select: **"🕵️ Conspiracy Theater (Non-Human Actor Surprises)"**
- This is the new mode with surprise actors

### Step 4: Scan for Hidden Activity
- Click: **"🔍 Scan for Hidden Non-Human Activity"**
- Watch the dramatic scanning process:
  ```
  🔍 Analyzing Prague districts for suspicious activity...
  📡 Scanning letna_park for non-human activity...
  🚨 ANALYZING DATA FOR SUSPICIOUS PATTERNS...
  ⚠️ MULTIPLE ANOMALIES DETECTED!
  ```

### Step 5: Watch Surprise Revelations
Actors will pop out one by one:
```

📊 Evidence: Urban Index 0.847 indicates coordinated expansion
🎭 MANIFESTED: The Concrete Collective of Old Town
```

### Step 6: Experience the Conflicts
- Actors refuse rational discussion
- They make impossible demands
- Conflicts escalate through absurdity
- Eventually leads to meta-theatrical breakdown

## ⚠️ Troubleshooting

### If Nothing Happens:
1. Make sure you're in the project directory: `c:/dev/Satelite`
2. Activate virtual environment: `spectral_env\Scripts\activate`
3. Check API key is in `.env` file

### If Imports Fail:
```bash
# Test imports
python -c "import sys; sys.path.append('core'); from conspiracy import NonHumanActorDetector; print('✅ Working')"
```

### If Browser Doesn't Open:
- Manually go to: **http://localhost:8501**
- Or try: `python -m streamlit run core/theater/civic_theater_stage.py --server.headless false`
